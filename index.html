Refleksi Belajar

Pelajari cara merepresentasikan algoritma dan prosedur dalam bentuk flowchart melalui simbol, urutan proses, percabangan, dan perulangan. Selanjutnya, terapkan konsep tersebut untuk menyelesaikan kasus sederhana dalam konteks Geologi dan Pertambangan.

Apa itu Flowchart?

Flowchart adalah diagram yang menampilkan langkah-langkah dan keputusan untuk melakukan sebuah proses dari suatu program. Setiap langkah digambarkan dalam bentuk diagram dan dihubungkan dengan garis atau arah panah.

Fungsi: Menyederhanakan rangkaian prosedur agar mudah dipahami, menjadi dokumentasi alur kerja, dan membantu mencari kesalahan (debugging) sebelum mempraktikkannya langsung.

Hubungan dengan Algoritma: Algoritma adalah urutan langkah logis penyelesaian masalah (berupa teks), sedangkan flowchart adalah representasi visual dari algoritma tersebut.

Simbol Dasar Flowchart
Terminator Mulai / Selesai (Bentuk Oval)
Process Proses / Tindakan (Bentuk Persegi Panjang)
Input / Output Data Masuk/Keluar (Jajar Genjang)
Decision Percabangan/Kondisi (Belah Ketupat)
Flowline Arah aliran proses
Struktur Umum
  • Sequence (Urutan): Proses berjalan lurus dari atas ke bawah.
  • Decision (Percabangan): Memiliki kondisi Ya/Tidak yang memecah alur.
  • Loop (Perulangan): Alur kembali ke proses sebelumnya sampai kondisi tertentu terpenuhi.

Kesalahan Umum: Tidak ada simbol START/END, arah panah terbalik/tidak ada, simbol Decision tidak memiliki cabang Ya/Tidak, dan terjadi infinite loop (perulangan tanpa henti).

      Evidence Room (Bukti-Bukti Investigasi)

      Setiap keputusan harus didukung oleh bukti. Periksa setiap sumber sebelum menggunakannya dalam analisis.

      Evidence 1 Belum ditinjau
      Data Telemetri Task Manager

      CPU: 35%, Memory (RAM): 89%, Disk SSD: 15%. Menunjukkan penggunaan memori mendekati kapasitas maksimum saat banyak aplikasi dibuka bersamaan.

      Evidence 2 Belum ditinjau
      Spesifikasi Hardware Laboratorium

      Processor Intel i3, RAM 4 GB DDR4, Storage SSD 256 GB, OS Windows 11. Windows 11 secara umum membutuhkan RAM minimal 4 GB hanya untuk berjalan optimal.

      Evidence 3 Belum ditinjau
      Dokumentasi Resmi Microsoft Support

      Mendokumentasikan bahwa ketika konsumsi RAM mendekati 100%, Windows 11 akan memindahkan data sementara ke Virtual Memory di storage (Paging), yang berakibat pada penurunan respon alokasi memori.

      Evidence 4 Belum ditinjau
      Artikel Blog Teknologi Umum

      Artikel bertajuk "Trik Komputer Cepat". Menyebutkan bahwa komputer lambat pasti disebabkan oleh virus atau registry penuh, dan menyarankan mendownload aplikasi "RAM Booster 2026".

      Evidence 5 Belum ditinjau
      Forum Diskusi Komunitas Komputer

      Beberapa teknisi menyarankan untuk mengecek penggunaan RAM pada tab Performance Task Manager dan menutup tab browser yang berlebihan atau menambah memori fisik.

      Evidence 6 Belum ditinjau
      Video Tutorial YouTube

      Judul "Mempercepat Komputer Tanpa Tambah Hardware". Menyarankan mematikan Windows Defender dan memodifikasi registry sistem secara manual.
